# 洛神赋安装说明

适用环境：Apple Silicon Mac，macOS 14 或更高版本。

1. 打开 `洛神赋_1.0.2_arm64.dmg`，把“洛神赋”拖入“应用程序”。
2. 首次启动时，在 Finder 的“应用程序”中右键“洛神赋”并选择“打开”。
3. 如果系统仍拦截，在“系统设置 → 隐私与安全性”中选择“仍要打开”；也可在终端执行：

   ```bash
   xattr -dr com.apple.quarantine "/Applications/洛神赋.app"
   ```

4. 打开“设置”：Codex 使用官方账号登录；Deepseek API Key 由每位使用者自行填写并保存在本机钥匙串。
5. 新建项目时选择真实存在的本地工作目录，即可创建独立任务或“设计 → 实施 → 验证”流程。
6. 侧栏底部点击「贾维斯」可打开粒子窗口（透明、无边框、置顶）。把鼠标移到窗口上会出现控制条：可切换待机 / 聆听 / 思考 / 说话 / 执行，或用「演示」自动轮播。首次点 🎙 会请求麦克风权限，用来让粒子随说话音量起伏；拒绝也不影响使用，窗口会自动改用演示音效并在下方标明。窗口底部的输入框可以直接向贾维斯提问，回答会显示在气泡里并用系统语音念出来；点 ⚙ 可以调粒子外观、挑选播报音色与问答模型（音色列表只列出真正下载了语音数据的音色）。点 🎙 还能直接说话提问：边说边出字，说完自动发送；首次使用会分别请求麦克风与语音识别权限，识别在本机完成。

发给同事的 Codex 安装提示词：

> 请帮我安装“洛神赋”：打开我提供的 `洛神赋_1.0.2_arm64.dmg`，将 App 拖入“应用程序”。若 macOS 拦截未签名应用，请指导我通过右键“打开”或“隐私与安全性 → 仍要打开”完成首次启动；不要删除或修改我的 Codex 配置。启动后检查 Codex 登录状态，并提醒我自行填写 Deepseek API Key，不要要求我把密钥发给你。
